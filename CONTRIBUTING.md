# Contributing to DenOps Conductor

Contributions to DenOps Conductor are accepted under AGPL-3.0-only, the same license as the project. Submit only work you have authority to contribute, preserve existing notices, and identify any third-party source and its license. Contributors retain copyright; contributing does not assign ownership to DenOps Systems Inc. No contributor license agreement or copyright assignment is introduced here.

DenOps Systems Inc. is the planned publisher; company formation is pending. Project licensing and third-party dependencies are separate: dependencies keep their own licenses. Do not relicense bundled third-party code by adding project headers.

Keep credentials, environment secrets, private keys, production data, databases, and operational logs out of contributions and release source bundles. Keep repair scheduling, migration verification, deployment approval, and Final Sync safety checks intact. Run the checks documented in README.md before submitting changes.

The project uses the SPDX identifier `AGPL-3.0-only`; later license versions are not implicitly authorized. Distributors and operators of modified network-accessible versions must follow the full license, including its corresponding-source provisions. The built-in source download covers the current first-party source; release packaging must also include any required modifications, build/install materials, and notices for bundled dependencies.
